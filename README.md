### Featured project

**[Farmbt](https://github.com/Samthnalyst1234/Farmbt): a multi-agent AI research farm.**
Describe a problem area. Agents research it on the web, find what's still unsolved, stress-test each gap with a critic
and a majority vote, and design solutions checked against existing products and papers. It's built to stay reliable
on cheap models: schema-validated output, source grounding, page re-verification and resumable stages. It works with
Claude, Groq and xAI, and includes a local dashboard and 28 offline tests.
